# decision-004: Levels as data

**Status:** Accepted
**Date:** Before October 24, 2026

## Context

Levels need to be authored in an editor, checked for mistakes, and later possibly generated by code.

## Decision

A level is a data object. Levels are drawn in the Tiled editor, and a loader converts the Tiled output into level data and rejects invalid levels with clear messages.

## Consequences

A future level generator emits the same format. A reachability checker can test that every level is completable under the dimension rules. Overlapping Black and White tiles are turned into Gray tiles by the loader (decision-016).

## Alternatives considered

Levels written directly in code, or the game reading Tiled files without a validated format in between.
