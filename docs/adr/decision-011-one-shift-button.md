# decision-011: Shifting is one dedicated button with a cooldown, and nothing else

**Status:** Accepted
**Date:** October 24, 2026

## Context

The first design changed the background through timers, levers, and jumps as well as a button (decision-005). Playing with the idea showed those were less fun and less fair.

## Decision

The shift is one dedicated button with a cooldown (0.4 seconds), and it switches only between Black and White. The one exception is the Gray background, which can be reached by other means set in level data (decision-015).

## Consequences

All timer, lever, and jump-based flips are removed from the shift. Levers and buttons only operate traps and platforms, never the background. Shift gates stay timing-based.

## Alternatives considered

Timer, lever, and jump-based toggles (decision-005).
