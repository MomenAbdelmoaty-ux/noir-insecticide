# Noir Insecticide

A 2D sideview action roguelike platformer about culling a horde before you get outswarmed. Navigate the difficult map while avoiding deadly traps, using your arsenal of movement to outpace the intensifying swarm. Be resourceful with the strong weapons you find and the traps you can resuse. Kill enough enemies and unlock the door at the end before it's too late. The world exists in two colors, and you must expertly maneuver between the two dimensional phases to become the greatest exterminator!

**Play it:** https://MomenAbdelmoaty-ux.github.io/noir-insecticide/

**Status:** work in progress. The first public version is planned for December 8, 2026.

## Run it locally

```
git clone https://github.com/MomenAbdelmoaty-ux/noir-insecticide.git
cd noir-insecticide
npm installs
npm run dev
```

Then open http://localhost:5173/noir-insecticide/ in your browser.

## Built with

TypeScript, Phaser, Planck.js, Vite, and Vitest.
